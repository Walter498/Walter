## 手动使用与覆盖风险

本文件不会自动安装、不会自动换源库、不会修改软件中的源设置。下载文件名为 `lizimh.js`，但其源 key 仍为 `lizimh`，**不是可无风险并排安装的另一来源**。在软件中手动更新同 key 源，可能覆盖原栗子源脚本；不要直接覆盖未知私有修改。

1. 先导出并保留自己正在使用的栗子源脚本，当前设备版本与私人改动未读取。
2. 对比版本与改动，确认要使用评论版后，才由你手动使用软件支持的同 key 源更新入口。不要删除账号、收藏、历史或图片缓存，不必切换整个源库或重装 IPA。
3. 评论版脚本的自身更新 URL 指向本独立分支；但原主源库、其他更新入口或用户手动更新仍可能重新覆盖此文件。不要把 main 版与评论版自动更新混用。
4. 需要回退时恢复自己导出的脚本，不删除源数据。
